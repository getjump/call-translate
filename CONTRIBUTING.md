# Continuing the experiment

This repository is archived and unmaintained. There is no expectation that issues or pull requests will be reviewed. Fork it for continued work.

Start with README.md, STATUS.md and the evidence index. Reproduce one measurable call/audio scenario before claiming broad device support. Keep synthetic protocol verification separate from real modem capture and remote audibility. Never commit API keys, call recordings, private transcripts, device identifiers or model/runtime binaries.

The root MIT license covers project-authored code. Check third-party and model/runtime terms separately. Preserve upstream notices and pins when changing vendored dependencies.

No application backend is hosted for you. Provider credentials and billing remain your responsibility.

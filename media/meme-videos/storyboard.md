# Call Translate - telephone meme storyboard

Two vertical 19s films for a Russian-speaking audience. The same clearly adult original cartoon hero supplies the joke. The phone interface is the focal point after the rehearsal. Calls go to a fictional Serbian beverage-delivery service. The agent interface is explicitly labeled as a concept.
